# Ledger & Leviathan

A single-page briefing on whether Ethereum, stablecoins and AI agents can pressure governments, which other technologies matter as much or more, and what that looks like from Sydney.

It is an analytical essay with interactive tools: a state-function reader, a toy scenario model, a confidence-tagged timeline from 2026 to 2050, technology cards, a society grid, and deep dives on Australia, Singapore, the United States, the United Kingdom and Thailand. The scenario sliders are a transparent weighting, not a forecast. Sources are linked and dated.

## Run locally

```bash
npm install
npm run dev
```

The dev server binds to port **43123**.

```bash
npm run build
npm run preview
```

`npm run check:model` checks that the scenario presets still land on the intended leading scenario.

## Stack

Vite, React, TypeScript and Tailwind. Charts use Recharts. There is no backend and no account.

## Reading the page

Claims are separated into evidence, inference and speculation in the prose. Market figures, especially stablecoin floats, are a snapshot (23 November 2026) and move. Nothing on the page is financial, legal or tax advice.
